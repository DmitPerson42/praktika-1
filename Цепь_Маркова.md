# Цепь Маркова

**Что это такое, простыми словами.**

Цепь Маркова - это модель процесса, который переходит из одного состояния в
другое, и **следующее состояние зависит только от текущего**, а не от всей
истории до него. Это свойство называется **марковским**: «будущее не помнит
прошлое, если знает настоящее».

Пример: прогноз погоды. Если сегодня дождь, завтра с вероятностью 0.7 снова
дождь, а с вероятностью 0.3 - ясно. Какая была погода позавчера, уже не важно.

---

## Формальное определение

Цепь Маркова - это последовательность случайных величин
`X₀, X₁, X₂, ...`, принимающих значения из множества состояний `S`, для
которых выполняется:

```
P(Xₙ₊₁ = j | Xₙ = i, Xₙ₋₁ = iₙ₋₁, ..., X₀ = i₀) = P(Xₙ₊₁ = j | Xₙ = i)
```

Правая часть означает: вероятность перехода `i -> j` не зависит от того, как
мы попали в `i`.

---

## Матрица переходов

Все вероятности переходов собираются в таблицу `P`, где элемент `P[i][j]` -
вероятность перейти из состояния `i` в состояние `j`.

Свойства матрицы:
- `P[i][j] >= 0` - вероятности не отрицательны;
- **сумма каждой строки равна 1** - из любого состояния куда-то перейти надо.

Пример для двух состояний:

```
        дождь   ясно
дождь [  0.7    0.3 ]
ясно  [  0.4    0.6 ]
```

---

## Что считается по цепи

### 1. Вероятность пути

Вероятность конкретной последовательности - произведение переходов:

```
P(дождь -> дождь -> ясно) = 0.7 * 0.3 = 0.21
```

### 2. Распределение через n шагов

Если `v₀` - вектор стартовых вероятностей (например, `[1, 0]`, если сегодня
дождь), то через `n` шагов:

```
vₙ = v₀ · Pⁿ
```

### 3. Стационарное распределение

Это распределение `π`, которое **не меняется** после перехода:

```
π · P = π
```

Смысл: как бы процесс ни начался, через много шагов он забудет старт и
выйдет на эти доли времени в каждом состоянии. Для примера выше:
`π ≈ [0.571, 0.429]` - примерно 57% времени дождь.

Для конечной цепи с положительными вероятностями стационарное распределение
существует и единственно, если цепь **эргодична** (неразложима и
непериодична).

---

## Код: маленький пример

```python
import numpy as np

# строки - откуда, столбцы - куда: [дождь, ясно]
P = np.array([[0.7, 0.3],
              [0.4, 0.6]])

# старт: сегодня дождь
v = np.array([1.0, 0.0])

# прогноз на 5 дней вперёд
for day in range(1, 6):
    v = v @ P
    print(f"день {day}: дождь {v[0]:.3f}, ясно {v[1]:.3f}")

# стационарное распределение - левый собственный вектор с собственным
# значением 1, нормированный на сумму 1
values, vectors = np.linalg.eig(P.T)
stationary = np.real(vectors[:, np.argmin(np.abs(values - 1))])
stationary = stationary / stationary.sum()
print("стационарное:", stationary.round(3))
```

Результат: уже к пятому дню вероятности почти совпадают со стационарными
`[0.571, 0.429]`.

## Зачем это нужно в машинном обучении

- **Языковые модели.** Простейшая генерация текста - цепь Маркова по словам:
  следующее слово выбирается по частотам после текущего. Именно это делает
  «цепь Маркова n-го порядка» в учебных примерах генерации текста.
- **Прогноз погоды, продажи, очереди.** Всё, где состояние меняется шаг за
  шагом, а память о прошлом коротка.
- **Скрытая марковская модель (HMM).** Состояния не видны напрямую, видны
  только наблюдения. Применяется в распознавании речи и в биоинформатике.
- **Обучение с подкреплением.** Марковский процесс принятия решений (MDP) -
  это цепь Маркова плюс действия и награда. На нём стоит вся теория RL.

---

## Чем цепь Маркова отличается от того, что мы делаем в практикуме

В практикуме 1 модель предсказывает **один ответ сразу** по признакам строки:
цена дома, диагноз, вид ириса. Прошлых строк нет, порядка нет.

Цепь Маркова нужна там, где есть **последовательность**: день за днём,
слово за словом, кадр за кадром. Она описывает не «объект», а **переход**.

---

## Ограничения

- **Память длиной в один шаг.** Реальные процессы часто зависят от истории
  глубже. Лечится цепью порядка `k` (состояние = последние `k` шагов), но
  тогда состояний становится экспоненциально больше.
- **Матрицу надо откуда-то взять.** В реальной задаче её оценивают по
  частотам переходов в данных, и при редких состояниях оценка шумная.

---

## Итог одной строкой

Цепь Маркова - это матрица вероятностей переходов между состояниями, где
следующий шаг зависит только от текущего; главные результаты - распределение
через `n` шагов (`v₀ · Pⁿ`) и стационарное распределение (`π · P = π`).
