# Практика по машинному обучению

Четыре учебных проекта по классическим алгоритмам машинного обучения.
Каждый ноутбук содержит полный цикл работы: от загрузки данных
до оценки качества модели и записи эксперимента в MLflow.

## Состав работ

| № | Алгоритм | Датасет | Задача | Тип задачи |
|---|---|---|---|---|
| 1 | Линейная регрессия | California Housing | предсказание стоимости жилья | регрессия |
| 2 | Логистическая регрессия | Breast Cancer | злокачественная / доброкачественная опухоль | бинарная классификация |
| 3 | Дерево решений | Iris | определение вида ириса | многоклассовая классификация |
| 4 | Случайный лес | Wine | определение сорта вина | многоклассовая классификация |

## Что есть в каждом ноутбуке

1. **Ячейка зависимостей** — все библиотеки с пояснением, зачем каждая нужна.
2. **Описание датасета** — источник, размер, смысл каждого признака,
   что именно предсказывается.
3. **Разведочный анализ (EDA)**:
   * общий вид данных и статистика;
   * проверка пропусков;
   * проверка дубликатов;
   * поиск аномалий и выбросов по правилу IQR;
   * распределения признаков (гистограммы, «ящики с усами»);
   * матрица корреляции.
4. **Построение и обучение модели** с объяснением каждого параметра.
5. **Оценка качества** — метрики, матрица ошибок, анализ ошибок.
6. **Эксперименты в MLflow** — сравнение нескольких вариантов модели.
7. **Выводы** — что получилось, чему учит задача, что можно улучшить.

## Ключевые результаты

| Модель | Основная метрика | Значение |
|---|---|---|
| Линейная регрессия | R² на тесте | 0.58 (0.65 после очистки выбросов) |

## MLflow

Все эксперименты записываются в базу **mlflow.db**.
Чтобы открыть веб-интерфейс и посмотреть сравнение запусков:

```bash
mlflow ui --backend-store-uri sqlite:///mlflow.db
```

Затем откройте http://127.0.0.1:5000

Записанные эксперименты:

* `California_Housing_LinearRegression` — 2 запуска
* `Breast_Cancer_LogisticRegression` — 3 запуска
* `Iris_DecisionTree` — 3 запуска
* `Wine_RandomForest` — 4 запуска

## Основные выводы по работам

**Линейная регрессия.** Качество ограничено тремя причинами: линейная
модель не улавливает нелинейные зависимости, цена в датасете обрезана
сверху (около 5 % домов), и часть признаков сильно связана между собой.
Очистка выбросов подняла R² с 0.58 до 0.65.

**Логистическая регрессия.** Точность около 0.99, ROC-AUC 0.998.
Главный вывод: в медицинской задаче accuracy обманчива —
нужно смотреть на recall для класса «злокачественная»,
потому что пропустить болезнь страшнее, чем ошибочно её заподозрить.

**Дерево решений.** Наглядно показано переобучение: дерево без ограничений
идеально описывает обучающие данные, но хуже работает на тестовых.
Найдена оптимальная глубина перебором. Важность признаков совпала
с результатами визуального анализа.

**Случайный лес.** Ансамбль из 100 деревьев дал абсолютную точность
на тестовой выборке, кросс-валидация — около 0.97. Показано, что после
25–50 деревьев качество выходит на плато. Отдельно разобрано расхождение
между корреляцией и важностью признаков: лес находит пользу
в нелинейных зависимостях, которые корреляция не видит.
