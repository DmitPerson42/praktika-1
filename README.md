## Что в репозитории

Четыре модели из методички, каждой — свой датасет и отдельный файл.

| № | Модель | Датасет | Размер | Тип задачи |
|---|---|---|---|---|
| 1 | Линейная регрессия | Abalone (UCI) | 4177 | регрессия, предсказание колец раковины |
| 2 | Логистическая регрессия | Heart Disease, Cleveland (UCI) | 303 | бинарная классификация |
| 3 | Дерево решений | Mushroom (UCI) | 8124 | бинарная классификация |
| 4 | Случайный лес | Bike Sharing Demand, часовые данные (UCI) | 17379 | регрессия, предсказание спроса |

Датасеты не пересекаются между собой и не повторяются с практикой №2
(Palmer Penguins, MNIST, Airline Passengers).

## Файлы

| Файл | Что внутри |

| `1_Линейная_регрессия.ipynb` | Abalone: One-Hot по полу, стандартизация, сопоставление с полиномом и Ridge по валидации, анализ остатков на гетероскедастичность и мультиколлинеарность |

| `4_Случайный_лес.ipynb` | Bike Sharing: разбор даты на циклические признаки, важность признаков, обоснование типа разбиения замером |

## Как запустить

Ноутбуки рассчитаны на **Google Colab**.

1. Открыть `.ipynb` в Colab: **Среда выполнения → Выполнить все**.
2. Датасеты подгружаются автоматически с официальных зеркал UCI. Нужен интернет
   при запуске — это единственное требование к окружению.
3. В ноутбуке 1 при первом запуске скачается `abalone.data` (~11 КБ).

Локально:

```bash
pip install -r ../requirements.txt
```

## Что общего у четырёх работ

* **Ячейка 1 — зависимости, ячейка 2 — все импорты** с пояснением, зачем нужна
  каждая библиотека. Больше нигде импортов нет.
* Логика — в ячейках с кодом, все пояснения — в markdown.
* **Очистка данных показана кодом в каждой работе**, даже там, где датасет
  чистый. Найдено по-настоящему: 6 пропусков «?» в Heart Disease и 2480 таких
  же в Mushroom — стандартные методы pandas их не видят, потому что это строки,
  а не `NaN`.
* **EDA в каждой работе:** распределения и матрица корреляции. Для грибов
  корреляция строится по top-N признаков — 115 столбцов читать невозможно,
  и это решение объяснено.
* **Утечки исключены.** В Bike Sharing удалены `casual`, `registered` и
  `instant` — иначе `casual + registered = count` дала бы идеальную точность
  без всякого обучения.
* **Базовая линия в каждой работе**, и сравнение идёт с сильнейшей из них.
  У логистической регрессии и дерева решений базовая линия честно показана
  как бесполезная: ROC-AUC 0.5 и нулевые precision с recall.
* Обучающая, валидационная и тестовая выборки разделены. Гиперпараметры
  подбираются по валидации, тест используется один раз в конце.
* `random_state` зафиксирован, результаты воспроизводятся.
* В каждой работе есть раздел об **ограничениях** — с числами, а не общими
  словами. Примеры: гетероскедастичность остатков в 2.3 раза, мультиколлинеарность
  r = 0.99 между длиной и диаметром, «признак-лазейка» `odor` с V Крамера 0.971,
  рост спроса ×1.52 за два года.
